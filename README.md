## Welcome!
This is the Github page for Sebastiaan den Broeder's AI Exposure Scan tool for the University of Amsterdam.
## URL
Personal URL: [tools.denbroeder.eu/host/assessment](https://rss.denbroeder.eu/host/assessment/)
Public URL: [https://github.com/ai-tlc/uva-assessment](https://github.com/ai-tlc/uva-assessment)

### Faculty-specific URLs
The tool can automatically select a faculty from the URL. For instance: 

- `github.com/ai-tlc/uva-assessment/#/fmg`  → FMG
- `github.com/ai-tlc/uva-assessment/#/fdr`  → FdR
